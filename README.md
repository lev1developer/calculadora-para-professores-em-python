# 📚 Calculadora de Média Escolar em Python

Um projeto simples desenvolvido em Python para calcular a média final de um aluno com base nas notas dos quatro bimestres escolares.

O programa solicita o nome do aluno, recebe suas quatro notas e calcula a média aritmética utilizando uma função.

## ⚙️ Funcionalidades

- Solicitar o nome do aluno;
- Receber as notas dos quatro bimestres;
- Armazenar as notas em uma lista;
- Calcular a média final utilizando uma função;
- Exibir o resultado com o nome do aluno.

## 🛠️ Tecnologias utilizadas

- **Python 3**

## 🚀 Como executar

### Pré-requisito

Ter o Python 3 instalado no computador.

### Passo a passo

1. Clone o repositório:

   ```bash
   git clone https://github.com/lev1developer/calculadora-para-professores-em-python.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd calculadora-para-professores-em-python
   ```

3. Execute o programa:

   ```bash
   python calculadora.py
   ```

   *Se o arquivo tiver outro nome, substitua `calculadora.py` pelo nome correto.*

## 💻 Exemplo de execução

```text
Digite o nome do aluno: Felipe
Digite a nota do Felipe no 1º bimestre: 8
Digite a nota do Felipe no 2º bimestre: 7
Digite a nota do Felipe no 3º bimestre: 9
Digite a nota do Felipe no 4º bimestre: 8

Média de Felipe: 8.0
```
